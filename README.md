## 🚀 Featured Project — csGPT

<div align="center">

> **A full-stack AI chat application powered by a locally running LLM via Ollama**
> *Where Generative AI meets Full Stack Engineering*

[![csGPT](https://img.shields.io/badge/🤖%20Live%20Demo-csgpt.farhankhan.in-brightgreen?style=for-the-badge)](https://csgpt.farhankhan.in)
[![Repo](https://img.shields.io/badge/GitHub-csGPT%20Repo-181717?style=for-the-badge&logo=github)](https://github.com/farhan-khan11/csGPT)
[![Tech Report](https://img.shields.io/badge/📄%20Technical%20Report-PDF-red?style=for-the-badge)](https://github.com/farhan-khan11/csGPT/blob/main/docs/FarhanKhan_csgpt_Technical-Report.pdf)

| Feature | Details |
|---|---|
| 🧠 AI Engine | Ollama — locally hosted LLM (no paid APIs) |
| ⚡ Streaming | Token-by-token response streaming |
| 🔐 Auth | JWT-based authentication |
| 🎨 Frontend | React.js + Tailwind CSS |
| 🛠️ Backend | Node.js + Express.js |
| 🗄️ Database | MongoDB + Mongoose |
| 🔒 Privacy | All inference runs locally on the server |
